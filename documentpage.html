JavaScript

This section covers JavaScript programming language.

function greet(name) { return `Hello, ${name}!`; } console.log(greet("Awais"));

This code defines a function called greet that accepts a name and returns a greeting message. The result is displayed in the console

Python

This section covers Python programming language.

def greet(name): return f"Hello, {name}!" print(greet("Awais"))

This Python function takes a name as input and returns a greeting. The print() function displays the message in the terminal

Java

This section covers Java programming language.

public class Main { public static void main(String[] args) { System.out.println("Hello, World!"); } }

This is a basic Java program. The main method is the entry point of the application, and System.out.println() prints text to the console.

C++

This section covers C++ programming language.

#include using namespace std; int main() { cout << "Hello, World!" << endl; return 0; }

This C++ program uses the iostream library to display text. cout outputs the message, and return 0 indicates successful execution.
